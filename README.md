# Local Python To-Do App

A small browser-based to-do list built with Python's standard library. It needs no package installation.

## Run it

1. Open a terminal in this folder.
2. Run `python app.py`.
3. The app opens in your browser at <http://127.0.0.1:8000>.


Tasks are saved in `tasks.json` beside the app.

## Run tests

```text
python -m unittest test_app.py
```
